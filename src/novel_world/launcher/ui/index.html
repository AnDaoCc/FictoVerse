            使用指南
            
            
            FictoVerse（虚构宇宙）启动器完整使用说明
            
          
            

          
            
            
            
              快速开始
              
            
                
              
                  
            1. 首次使用请进入「环境安装」页面，点击「重新检测」
              2. 
                  
            2. 确认 Python、虚拟环境、依赖状态均显示绿色对勾
              3. 
                  
            3. 回到「一键启动」页面，点击「一键启动」按钮
              4. 
                  
            4. 等待依赖安装和 Web 服务启动（首次可能需要几分钟）
              5. 
                  
            5. 服务启动后会自动打开浏览器，进入 Web 界面即可使用
              6. 
                
            
              
            
            
            

            
            
              一键启动
              
            
                
            点击「一键启动」按钮会自动完成：检查 Python 环境 → 创建/更新虚拟环境 → 安装项目依赖 → 启动 Web 服务。
            
                
            服务启动成功后：
            
                
              
                  
            • 按钮变为「重新打开浏览器」，可随时重新打开 Web 界面
              • 
                  
            • 主页显示服务地址和端口号
              • 
                  
            • 状态徽章变为绿色「运行中」
              • 
                
            
                
            点击左下角红色「停止服务」按钮可关闭 Web 服务。
            
              
            
            
            

            
            
              环境安装
              
            
                
            
                  
            Python
            系统需安装 Python 3.10 或更高版本。如未安装，点击「安装 Python」可通过 winget 自动安装。
            
                  
            虚拟环境 (.venv)
            项目依赖隔离在项目根目录的 .venv 文件夹中，与系统 Python 互不影响。
            
                  
            WebView2
            启动器界面依赖 Edge WebView2 运行时，Windows 10/11 通常已预装。
            
                  
            一键安装
            点击「一键安装最新环境」自动完成以上所有检测和安装步骤。
            
                  
            重建虚拟环境
            勾选「重建虚拟环境」后安装，会先删除现有 .venv 再重建，适合出问题时使用。
            
                
            
              
            
            
            

            
            
              Python 版本切换与升级
              
            
                
            系统安装多个 Python 版本时（如 3.12 和 3.13），主页「系统信息」的 Python 行会出现下拉框，可切换使用的版本。
            
                
            切换版本会重建虚拟环境并重新安装所有依赖，请确认后再操作。
            
                
            旁边的 ↑ 升级按钮 用于将当前 Python 升级到最新兼容版本（通过 winget），依赖包同理。
            
              
            
            
            

            
            
              世界管理
              
            
                
            在启动器内直接查看、创建、删除虚构世界。首次使用需先启动 Web 服务。
            
                
            每个世界独立保存数据，进入世界聊天后 AI 会读取其设定进行角色扮演或叙事。
            
              
            
            
            

            
            
              控制台
              
            
                
            实时显示启动器运行日志，包括：Python 检测、依赖安装进度、服务启停状态。
            
                
            任务执行期间可自由切换到控制台查看实时输出。点击「清空日志」清除当前显示。
            
              
            
            
            

            
            
              设置详解
              
            
                
            API 提供商
            
                
            配置大模型 API（OpenAI、Anthropic、Gemini 等）。数据保存在本地数据库，无需启动 Web 服务即可编辑。选择厂商预设可自动填充 Base URL 和默认模型。
            
                
            酒馆预设导入
            
                
            导入 SillyTavern Preset JSON 文件，自动写入全局默认采样参数与提示词分层，与 Web 设置同步。
            
                
            MOD 系统
            
                
            安装扩展功能：Python Hook、前端脚本、世界内容包。支持 .zip 格式安装，与 Web 设置共享启用状态。点击「打开 MOD 目录」可手动管理文件。
            
                
            启动偏好
            
                
            「启动后自动打开浏览器」控制一键启动后是否自动弹出 Web 界面。可通过环境变量 NOVEL_WORLD_ROOT 指定项目根目录。
            
                
            外观设置
            
                
            自定义启动器的背景图片、模糊度和叠加颜色。支持本地图片文件。
            
              
            
            
            

            
            
              常见问题
              
            
                
            
                  
            Q: 启动后浏览器没有自动打开？
            
                  
            检查「设置 → 启动偏好」中是否勾选了「自动打开浏览器」，或点击主页的「重新打开浏览器」按钮。
            
                  
            Q: 提示「未检测到 Python 3.10+」？
            
                  
            进入「环境安装」页面，点击「安装 Python」按钮通过 winget 自动安装，或手动从 python.org 下载安装。
            
                  
            Q: 依赖安装失败或超时？
            
                  
            检查网络连接，尝试关闭代理/VPN。可勾选「重建虚拟环境」后点击「一键安装最新环境」重试。如仍失败，查看「控制台」日志排查具体错误。
            
                  
            Q: 启动器界面无法打开或白屏？
            
                  
            需要安装 Edge WebView2 运行时：微软官网下载。Windows 11 通常已预装。
            
                  
            Q: Web 界面能打开但 AI 不回复？
            
                  
            检查「设置 → API 提供商」是否正确配置了 API Key、Base URL 和模型名称。可先测试 API Key 是否有效。
            
                  
            Q: 如何更新软件到最新版本？
            
                  
            前往 GitHub Releases 下载最新版本。源码用户覆盖文件后重启即可，打包版用户替换 exe 文件。
            
                  
            Q: 如何备份数据？
            
                  
            项目根目录下的 data/ 文件夹包含所有用户数据（世界、对话、设置），备份该文件夹即可。
